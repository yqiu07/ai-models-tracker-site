### Step 2: 增量去重 — `main.py::step_dedup_against_master()`

| 属性 | 值 |
|------|-----|
| **执行方式** | 🤖 自动化程序（内联函数） |
| **是否调用大模型** | ❌ |

#### 🔴 Step 2 已知问题

1. **去重标准过于宽泛** — `deepseek-v4` 和 `deepseek_v4` 会被视为同一个模型，但 `deepseek-v4` 和 `deepseek-v4-flash` 不会
2. **时间窗口过滤已加** — 平台目录的模型按"平台上架时间"过滤窗口外数据 ✅
3. **RUN_ID 跨步骤不持久** — `RUN_ID` 是 `main.py` 第 89 行的模块级全局常量 `RUN_ID = datetime.now().strftime("%Y%m%d_run%H%M")`，在每次 `python main.py` 启动时计算一次。如果步骤中断后通过 `--step 5` 重启，会生成新的 `RUN_ID`（如 `20260512_run1644`），而增量文件名包含旧 `RUN_ID`（如 `20260512_run1639.xlsx`），导致 `step_merge_and_archive()` 中 `INCREMENT_DIR / f"{RUN_ID}.xlsx"` 路径不匹配，找不到文件而跳过合并 🔴

### Step 3: LLM 审核 — `review_models.py`

| 属性 | 值 |
|------|-----|
| **执行方式** | 🤖 自动call大模型（子进程） |
| **是否调用大模型** | ✅ kuai GPT-5.5 |
| **API 配置** | `KUAI_API_KEY` + `KUAI_API_BASE` + `REVIEW_MODEL=gpt-5.5` |
| **Prompt 功能** | 名称规范性审核 + 旧模型检测 + 字段补全 + 重要性评级 |
| **产出** | 修改 `Object-Models-Updated.xlsx` 中的字段 + `review_report.md` |
| **超时** | 10 分钟（run_script 默认） |
| **温度** | 0.1 |

#### Prompt 要求 LLM 补全的字段

| 字段 | 来源 | 可靠性 |
|------|------|--------|
| 尺寸 | LLM 知识库 | ⚠️ 中（可能不是最新） |
| 模型发布时间 | LLM 知识库 | ⚠️ 中（容易幻觉） |
| 官网 | LLM 知识库 | ⚠️ 中（可能给出旧链接或错误URL） |
| 任务类型 | LLM 知识库 | ✅ 高（分类任务准确度高） |
| 公司名统一 | LLM 知识库 | ✅ 高 |
| 重要性评级 | LLM 判断 | ✅ 高 |

#### 🔴 Step 3 已知问题

1. **发布时间补全不可靠** — GPT-5.5 的训练数据有截止时间，对新模型的发布日期容易幻觉
2. **官网补全不可靠** — 可能给出过期链接、平台文档链接而非模型官网
3. **备注字段未补全** — 当前 Prompt 没有要求生成语义化备注（已在本轮修复，增强了 Prompt）
4. **无 web search 能力** — GPT-5.5 基于静态知识库，无法验证实时信息
5. **无分批逻辑** — 当前 `review_models.py` 中没有 batch/chunk/split 相关代码。如果新增模型数量较多（如 88 个），会将全部模型 JSON 一次性塞入 Prompt，可能超过 GPT-5.5 的输入/输出 token 限制导致截断

## 五、Step 4 数据校验的自动化方案

### 目标

对每个新增模型自动校验/补全以下字段：
1. **模型发布时间** — 模型提供方的官方发布日期（非平台上架时间）
2. **官网** — 模型提供方自己的官方页面（非代理平台文档）
3. **备注** — 语义化技术标签（架构/参数/亮点/定价等）

### 方案对比（基于阿里云官方文档 2026-05 验证）

| 方案 | 实现方式 | 优点 | 缺点 |
|------|----------|------|------|
| **A: DashScope Chat Completions + `enable_search`** | OpenAI 兼容 API + `extra_body={"enable_search": True}` | 已有 Key、改动最小、成本低 | 仅返回文本答案，不返回搜索引用源 |
| **B: DashScope Responses API + tools** | `client.responses.create(tools=[{"type":"web_search"}])` | 返回搜索引用、支持 web_extractor | 需要 openai SDK ≥1.x，代码改动稍多 |
| C: Perplexity API | `https://api.perplexity.ai/chat/completions` | 搜索质量高、带引用 | 需额外注册 Key、可能被云壳拦截 |
| D: kuai 转发 GPT-5.5 + tools | kuai API + tools 参数 | 模型强 | 未验证 kuai 是否透传 tools 参数 |

### 推荐方案：A（DashScope Chat Completions + `enable_search`）

理由：
1. `LLM_API_KEY` 和 `LLM_API_BASE` 已在 `.env` 中配置就绪
2. 阿里云官方文档确认：**Chat Completions API** 通过 `extra_body={"enable_search": True}` 即可启用联网搜索
3. 国内网络稳定，不受云壳限制（`dashscope.aliyuncs.com` 冒烟测试已通过）
4. 支持的模型范围广（来源：[阿里云官方文档](https://help.aliyun.com/zh/model-studio/web-search)）

### DashScope 联网搜索 — 支持的模型清单（已验证）

以下模型均支持 `enable_search=True`：

**千问系列（.env 中已配置 `LLM_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1`）**：
- `qwen3.6-plus`、`qwen3.6-plus-2026-04-02`
- `qwen3.5-plus`、`qwen3.5-plus-2026-02-15`
- `qwen3-max`、`qwen3-max-2025-09-23`
- `qwen-plus`、`qwen-plus-latest`
- `qwen-turbo`、`qwen-turbo-latest`
- `qwq-plus`

**第三方模型（通过 DashScope 调用也支持联网搜索）**：
- `deepseek-v4-pro`、`deepseek-v4-flash`、`deepseek-v3.2`、`deepseek-r1`
- `MiniMax-M2.1`
- `Moonshot-Kimi-K2-Instruct`

### 自动化 Step 4 的真实 API 调用方式

```python
import requests
import os

def call_qwen_with_web_search(prompt: str, model: str = "qwen3.6-plus") -> str:
    """调用 DashScope Chat Completions API（联网搜索模式）。
    
    来源：https://help.aliyun.com/zh/model-studio/web-search
    验证方式：Chat Completions API + extra_body.enable_search
    """
    api_key = os.environ.get("LLM_API_KEY", "")
    api_base = os.environ.get("LLM_API_BASE", "https://dashscope.aliyuncs.com/compatible-mode/v1")
    
    url = f"{api_base.rstrip('/')}/chat/completions"
    headers = {
        "Authorization": f"Bearer {api_key}",
        "Content-Type": "application/json",
    }
    payload = {
        "model": model,
        "messages": [{"role": "user", "content": prompt}],
        "temperature": 0.1,
        "max_tokens": 2000,
        # 关键参数：启用联网搜索（非 OpenAI 标准参数，通过顶层传入）
        "enable_search": True,
    }
    
    resp = requests.post(url, headers=headers, json=payload, timeout=60,
                         verify=os.environ.get("MODEL_NAVIGATE_TLS_VERIFY", "false").lower() != "false")
    resp.raise_for_status()
    return resp.json()["choices"][0]["message"]["content"]


def step_verify_with_web_search(increment_path: str):
    """Step 4: 对增量模型逐个调用联网 LLM 校验发布时间/官网/备注。
    
    执行逻辑：
    1. 读取增量 Excel
    2. 筛选需要校验的模型（发布时间/官网/备注任一为空）
    3. 逐个或分批调用 Qwen3.6-Plus + enable_search 校验
    4. 解析 JSON 结果回写到 DataFrame
    5. 保存校验后的增量 Excel
    """
    import pandas as pd
    import json
    
    df = pd.read_excel(increment_path)
    needs_verify = df[
        (df["模型发布时间"].isna() | (df["模型发布时间"] == "")) |
        (df["官网"].isna() | (df["官网"] == "")) |
        (df["备注"].isna() | (df["备注"] == ""))
    ]
    
    for idx, row in needs_verify.iterrows():
        prompt = f"""请联网搜索以下 AI 模型的最新信息，严格以 JSON 格式返回。

模型名称: {row['模型名称']}
公司: {row['公司']}
平台上架时间: {row.get('平台上架时间', '未知')}

请返回以下 JSON（如果搜索不到确切信息，对应字段返回空字符串）：
{{
  "模型发布时间": "YYYY-MM-DD（模型提供方官方公告发布日期，非平台上架日期）",
  "官网": "模型提供方自己的官方页面URL（如 https://api-docs.deepseek.com，不要填代理平台链接）",
  "备注": "核心技术特征，分号分隔（如：MoE架构；1T参数；262k上下文；GPQA 90.5%）"
}}"""
        
        try:
            result_text = call_qwen_with_web_search(prompt, model="qwen3.6-plus")
            # 从返回文本中提取 JSON
            json_match = re.search(r'\{.*\}', result_text, re.DOTALL)
            if json_match:
                result = json.loads(json_match.group())
                if result.get("模型发布时间"):
                    df.at[idx, "模型发布时间"] = result["模型发布时间"]
                if result.get("官网"):
                    df.at[idx, "官网"] = result["官网"]
                if result.get("备注"):
                    df.at[idx, "备注"] = result["备注"]
        except Exception as exc:
            print(f"  ⚠️ {row['模型名称']}: 校验失败 ({exc})")
            continue
    
    df.to_excel(increment_path, index=False)
    return len(needs_verify)
```

> **注意**：上述代码基于阿里云官方文档验证，`enable_search` 参数在 requests 直接调用时作为 JSON payload 的顶层参数传入（非 `extra_body` 包裹，那是 Python OpenAI SDK 的写法）。
